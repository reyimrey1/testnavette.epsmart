# PACE — Test Luc Léger (EPS)

Outil de terrain pour professeurs d'EPS : test Luc Léger (navette 20 m) synchronisé avec la bande-son officielle,
couloirs numérotés, repères 15/30/45 s, VMA, import de listes (Excel, CSV, Massar), export Excel/PDF, mode clair et mode hors ligne.

## Utilisation
Ouvrir la page, importer la liste de classe, télécharger la bande-son sur l'appareil (une seule fois), cocher le groupe et lancer le test.
Les données des élèves restent dans le navigateur de l'appareil : elles ne sont envoyées à aucun serveur.

## Bande-son
La bande-son du test Luc Léger est protégée par le droit d'auteur : **elle n'est pas incluse dans ce dépôt** et ne doit pas l'être.
Chaque utilisateur la télécharge sur son appareil pour un usage personnel ou scolaire.

## Hors ligne
Après une première visite en ligne, la page peut être ouverte sans réseau (service worker).
Sur téléphone : menu du navigateur › « Ajouter à l'écran d'accueil » / « Installer l'application ».
